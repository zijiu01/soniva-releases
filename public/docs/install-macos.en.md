# Download & install (macOS)

Open the version timeline, pick the version you want, and download the DMG that
matches your Mac's chip.

## Choose the right architecture

- Apple Silicon (M-series): download the `arm64` build
- Intel: download the `x64` build
- Not sure? Open  → About This Mac and check the Chip / Processor line

## Install

1. Open the downloaded `Soniva-<version>-<arch>.dmg`
2. Drag the Soniva icon into your Applications folder
3. On first launch, if macOS says the developer cannot be verified, go to
   System Settings → Privacy & Security and click Open Anyway at the bottom

Soniva is signed with a Developer ID and notarized by Apple, so this prompt
should not appear on a normal, online machine.
