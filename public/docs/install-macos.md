# 下载与安装（macOS）

从版本时间线进入对应版本，选择与你 Mac 芯片匹配的 DMG 安装包。

## 选择正确的架构

- Apple Silicon（M 系列）：下载 `arm64` 版本
- Intel：下载 `x64` 版本
- 不确定时，点左上角苹果菜单 →「关于本机」，查看「芯片 / 处理器」

## 安装步骤

1. 打开下载好的 `Soniva-<版本>-<架构>.dmg`
2. 把 Soniva 图标拖入「应用程序」文件夹
3. 首次打开时，如果系统提示「无法验证开发者」，前往「系统设置 → 隐私与安全性」，
   在底部点击「仍要打开」

Soniva 使用 Developer ID 签名并通过 Apple 公证，正常联网环境下不会出现上述拦截。
