# First launch & sign-in

Open Soniva after installing. The first launch loads the cloud studio.

## Sign in

- Sign in directly with Google / Apple
- The account is shared with the web app at `app.soniva.uk`

## Offline & network

- When disconnected the app shows a local offline page instead of a blank screen
- External links open in your system browser by default

## Local asset library

- A `.sonivalib` library file is created on first use; move it anywhere and it travels with you
- Duplicate audio imports are de-duplicated by fingerprint, so no copies are created
