# 常见问题与排障

## 打开时提示「已损坏」或「无法验证开发者」

先确认下载完整、且来自本仓库 Releases。若仍被拦截，可在终端执行：

```bash
xattr -dr com.apple.quarantine /Applications/Soniva.app
```

再重新打开。该命令只是移除浏览器下载留下的隔离标记，不会修改应用本身。

## 应用双击后白屏

0.1.0 为首次打包的内测版本，如遇白屏请先完全退出应用再重开一次，并确认网络可用。
若问题持续，请在仓库 Issue 中附上 macOS 版本、芯片架构与截图。

## 提示「另一个实例已在运行」

Soniva 使用单实例锁。请先在 Dock 中退出正在运行的窗口，或按 `⌘Q` 后再重新打开。

## 资源库相关

- 资源库文件（`.sonivalib`）损坏时，可从侧车文件重建索引
- 删除的素材会进入回收站，可在应用内恢复

## 仍未解决

请在 GitHub 仓库的 Issues 中反馈，并附上：macOS 版本、芯片架构、Soniva 版本号、
复现步骤与截图。
