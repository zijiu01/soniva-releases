# First public release

The first publicly distributed build of Soniva Desktop. Developer ID signing
and Apple notarization have passed (Gatekeeper accepted). Downloads are open.

## Desktop shell

- Loads the Soniva cloud studio; sign in with Google / Apple directly
- Single-instance lock, external links open in the system browser, offline page when disconnected
- macOS title bar adaptation with drag and hidden title bar

## Local asset library (.sonivalib)

- A portable SQLite-backed library file with full-text search
- Audio fingerprint de-duplication, so repeated imports do not create copies
- Soft-delete trash, index rebuild from sidecar files, multi-library registration and switching
- Filter-bar sorting: added time (new→old / old→new), name (A→Z / Z→A)

## Authoring & preview

- Studio UI matching the web app, with segmented long-text reading
- Thumbnails for images, video and PDF, plus quick preview with the space bar
- PDF text and box annotations wired into the canvas
- Layout pause shaping before reading: line breaks / tabs fed to sentence pauses

## Sharing, distribution & updates

- `.sonivapack` asset bundles
- Developer ID code signing + Apple notarization, dual-arch DMG (Apple Silicon / Intel)
- Built-in electron-updater for in-app updates in later versions

## Known issues

- The end-to-end auto-update flow has not been verified against a real older build
- A Windows build has not been started
