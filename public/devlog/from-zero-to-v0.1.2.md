# 从 0 到 v0.1.2：桌面端两个月开发全记录

Soniva 桌面端从 2026-08-24 立项到 2026-09-20 首次公开发布，28 个自然日、1148 个提交。
本篇是按天开发日志（见其余各日）的总览：每一步怎么走的、为什么这么走。

## 起点：网页版（2026-07-25）

monorepo 的第一个提交是 Create Next App 脚手架，当天完成独立 AI TTS 语音对话平台的
主体搭建——ChatGPT 官方设计规范的全套视觉与交互。之后一个月，网页版长出了对话、
语音合成、账号与计费。桌面端的一切都建立在这套云端工作台之上。

## 桌面端立项：批次 0-3（2026-08-24 → 08-26）

- **批次 0**：Electron 骨架，直接加载线上 Soniva，不复制一份 Web 代码。
- **批次 1**：外壳可用性——OAuth 零 Web 改动方案、外链分流给系统浏览器、离线页。
- **批次 2**：SonivaLibrary 内核，`.sonivalib` 格式：SQLite + 全文检索 + 音频指纹去重。
- **批次 3**：Bridge v1，contextBridge 接通库内核，`soniva-asset://` 支持 Range 流式取图。

## 资源库成形（2026-08 下旬）

资产存储参考 Eagle.cool 改成每个资产独立文件夹；资源库窗口拿到独立 preload/IPC，
React + Vite + shadcn 界面首个可用版本落地；文件夹树连续五轮真机验收打磨
（展开态持久化、拖拽归类、未归类筛选、统计数字）。Paddle/PayPal 结账窗口的
UA 与弹窗边界也在这一阶段收敛进应用内。

## 多语言、会话与模型（2026-09 上旬）

资源库界面分六个批次接入 i18n；AI 会话标签同步到导出资产；模型管理、本地语音
相关能力开始进入桌面端。

## 首次打包：批次 7（2026-09-09）

第一次把 Electron 应用打成 DMG：Developer ID 签名、Apple 公证、electron-updater
自动更新配置同日落地；打包前置检查脚本化。首次打包的白屏根因（`files` 漏了
`dist-renderer/`，开发环境完全复现不出来）靠 asar 自检脚本拦住，排障全程成文。
次日补齐 DMG 安装窗口背景并确认 publish 仓库指向。

## 冲刺与打磨（2026-09-11 → 09-19）

电子书阅读器、空格预览（QuickLook）、摘录卡、截图窗口化、划词气泡跨应用取词、
本地 TTS 三档量化包——高频迭代的一周，单日提交峰值 101 个（09-13）。订阅用户
在资源库被误判免费版的登录态信号问题在此期间修复。

## v0.1.2 发布（2026-09-20）

双架构 DMG（Apple Silicon / Intel）签名、公证、钉票据全部通过 Gatekeeper 实测，
上传 GitHub Releases 作为首个公开发布版本；本发布记录页同日上线。
自动更新的端到端验证与 Windows 版本列入下一步。
